# Ageless Arsenals — The Dread

The eight standard Dread and both registered Dread raid bosses each have a new baked model, painted material atlas, emissive mask and Blockbench project. Rhulk, Nezarec, the Husk’s Geist, and both Subjugator types retain their existing entity IDs, combat timers and collision dimensions.

## Rebuild the models

Run `python bake.py` with Python 3 and Pillow installed. The script writes the neutral rig to `models/<id>.json`, an editable visual project to `blockbench/<id>.bbmodel` and the compiled geometry and two texture atlases to `overlay/`. Edit the recipes in `sculpt.py` to regenerate every representation together. A Blockbench file is useful for examining proportions, material assignments and parentage. Edits saved only inside that file are independent of the recipe.

The recipe uses X and Z centers and the top edge in Y-down coordinates. The body origin is 24 model pixels above the vanilla origin so negative local Y points toward the head. Each child pivot is relative to its immediate parent. The hand owns each gun, glaive or blade throughout the animation. The Grim carries the intermediate wing-tip joint at the outer end of its leading spar, so the inner and outer membranes stay connected throughout the flap. Recentering a child in Blockbench requires a matching change to its descendants’ local pivots.

Material slots occupy 64-pixel tiles on a 512 × 128 atlas. UVs generated by Minecraft’s cube builder must stay inside the tile. Baking breaks long faces into smaller cuboids before export. Emissive materials are a sparse mask with zero alpha elsewhere. The shoulder pads on the Tormentor and Nezarec use separate light nodes keyed to the existing synchronized weak-point bitmask.

## Animation and integration

Compile the two Java files under `src/` with the mod’s normal Java 21 / NeoForge 1.21.1 classpath. Merge the contents of `overlay/` into the JAR. Register `DreadPoseMixin` in the client section of the mod’s `com.jax.destiny2mc.mixin` configuration. The type-specific pose sampler is installed only on the Dread branch of `FrontierModel`. Both the bestiary and the world use this model and its actual diffuse/emissive textures.

`DreadMotion` derives its poses from the server’s synchronized action clock, with fractional ticks for interpolation. The Husk blades peak at ticks 14 and 22 of the existing melee action. Grim inner and outer spars move out of phase. Attendants and Weavers aim their hand forks and cast with a free hand. Tormentor-family jumps use a crouch and overhead scythe, and Rhulk extends a leg while charging. To tune an attack animation, check the combat handler’s hit tick first. Strike timing and damage remain authoritative on the server.

## Checks

Run `python audit.py path/to/Ageless-Arsenals.jar` to compare the ten native geometry classes and twenty textures with the baked overlay, validate the parent graph and material bounds, and check each Blockbench project against its model. The optional `qa/DreadPoseCheck.java` fixture samples every rig through 210 combinations of action and age using the real Minecraft model classes. It checks the alternating Husk strikes, four shoulder damage masks, Rhulk’s kick and wing motion. These checks exercise client presentation. The server still controls the hit, whether it connects, and what happens to the target afterward.
