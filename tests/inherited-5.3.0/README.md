# Raid armor release checks

All gameplay fixtures are outside the production source set. Each native proof identifies the edition used; the standard and progression editions have identical armor and UI implementations. The new fixtures cover registry and material IDs, recipes, subclass perks, actual damage, loot rewards, native wearable poses, equipped player/armor-stand rendering, and the card and drawer UI. `results/` contains the recorded output. `GEAR-UI.md` and the feature documents in `docs/` describe the graphical drivers. The independent layout check covers 5,760 combinations and verifies the centered/flush distinction. Earlier version-specific measurements, controls and screenshot expectations are retained in the inherited test directories.

To run server fixtures, compile each separately with Java 21 against the shipped JAR and NeoForge's Minecraft 1.21.1 mapped development classpath, package it as a separate test mod with the ID specified on its event subscriber, and start it with the release in a disposable local world. Client fixtures require the real modded game and a local dedicated server. The standalone pixel checks require Python, NumPy and Pillow. Source builds require only the dependencies documented in the main README.
