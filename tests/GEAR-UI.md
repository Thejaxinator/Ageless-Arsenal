# Native equipment interface tests

`GearUiCheck` uses an ordinary NeoForge graphical client connected to its own local dedicated server. It obtains a legal four-active/two-passive loadout through a real Energy Binder, equips an Ace of Spades with alternate trait rolls, a reload masterwork and Major spec, and moves the cursor across the native workstation, inventory and Gunsmith. The tested hover set covers Healing Rift, a Legendary helmet, an Exotic helmet, a customized Exotic hand cannon and vanilla bread. The fixture also checks the small side notch, all six ammo themes, and vanilla's alternate detail view.

Compile the fixture against the matching release and mapped Minecraft 1.21.1 / NeoForge 21.1.266 classes, package it separately under the test mod ID `ageless_gear_ui`, and install it on the client. Give the test character operator permissions on a disposable server. Use Java 21, launch the client at 1440×810 with Minecraft GUI scale 3, and supply `-Dbinder.port=<local server port>` and `-Dbinder.shots=<absolute screenshot directory>`. The fixture exits after printing `GEAR UI COMPLETE`. The optional Linux `-Dgear.shift.helper=/path/to/shift_test_key.py` check drives Shift using XTest on the test display. Its only purpose is to exercise Minecraft's physical-key handling while that stack is hovered.

Run `python tests/fixtures/check_gear_pixels.py docs/previews/gear` (Pillow required) to measure each skin's first rendered glyph, the four centered layouts and two flush layouts, and the ability/gear rarity ribbons. The PNGs are native framebuffers.
